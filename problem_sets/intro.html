Problem Sets#

One graded problem set per chapter. Each is worth 100 points, split across three parts that build on each other:

  • Part A — Skill Checks (30 pts): short answers, auto-graded, unlimited attempts.

  • Part B — Visualization (35 pts): plots and interpretation, peer graded.

  • Part C — Open Ended (35 pts): one synthesis problem, peer graded.

Note

Each problem set is a standalone Jupyter notebook. The zip link below gives you the notebook and its data in a folder that runs as-is; the Download badge at the top of any problem page gives you the notebook on its own. The cells marked # YOUR CODE HERE are deliberately not executed when the book is built, so you receive them blank and ready to fill in.

Solutions are not published here.
