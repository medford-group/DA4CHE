Part A — Skill Checks (30 pts)#

We will start with some basic questions that we should always ask before building a model from time series data. First, how much of the signal is fast noise that a moving average would remove? Second, how long does the signal “remember” its past values? Third, if some data are missing, how well can we fill them in? Each question below looks at one of these for one of the tags.

A1. How much of the furnace pressure is fast fluctuation? (10 pts)#

Exercise 1

A moving average splits a signal into two parts. The average itself keeps the slow changes. What is left over, the residual (raw signal minus the average), holds the changes that are faster than the window. Comparing the residual’s variance with the raw signal’s variance tells us what fraction of the signal’s variability is fast fluctuation. A value near 0 means the signal is mostly slow drift, and a value near 1 means it is mostly fast noise.

  1. Smooth furnace_pressure with a trailing 5-minute moving average, .rolling(60).mean() (60 samples at 5 s each). Trailing means each average uses only the current and past samples, which is the default for .rolling.

  2. Compute the residual, furnace_pressure - moving_average. Its first 59 values are NaN, which .var() skips.

  3. Divide the residual’s variance by the raw signal’s variance, residual.var() / furnace_pressure.var().

Assign that fraction to frac_resid.

A3. Filling a gap (10 pts)#

The desuperheat_water_flow tag has a real 2.3-minute gap at 06:22. We would like to know how well linear interpolation fills a gap like that, but we cannot check a fill of a real gap, because the true values are missing. The standard trick is to make artificial gaps in data we do have, fill them, and compare the fill with the values we removed.

Here we make gaps about as long as the real one: 2 minutes, which is 24 samples at 5 s each. A single gap could land on a quiet stretch or a busy one by luck, so we make six of them, one every 4 hours, and average the error over all six. The data start at midnight and there are 720 samples per hour, so the gap starting at hour \(h\) begins at row \(720h\).

Part C — Open Ended (35 pts)#

One thing that is easy to forget is that the numbers in this file are not exactly what the sensors measured. The historian rounded each value to two decimals, and many plant historians also compress the data with the swinging-door algorithm from the chapter. This does not change a trend plot very much, but it can change the statistics we computed in Part B. In Part C we will see how much, and how fine the historian’s settings need to be before we can trust those statistics.

Use the chapter’s swinging-door function, given here:

def swinging_door(t, y, delta):
    """Swinging-door (SDT) compression: indices of the points a historian keeps."""
    keep = [0]
    t0, y0 = t[0], y[0]
    s_max, s_min = -np.inf, np.inf          # lower-door / upper-door slopes
    for i in range(1, len(y)):
        dt = t[i] - t0
        s_min = min(s_min, (y[i] + delta - y0) / dt)
        s_max = max(s_max, (y[i] - delta - y0) / dt)
        if s_max > s_min:                   # corridor closed: archive previous point
            keep.append(i - 1)
            t0, y0 = t[i - 1], y[i - 1]
            dt = t[i] - t0
            s_min = (y[i] + delta - y0) / dt
            s_max = (y[i] - delta - y0) / dt
    keep.append(len(y) - 1)
    return np.array(sorted(set(keep)))

Exercise 5

1. Rounding. The historian stored every value to two decimals, so the true readings are gone and we cannot undo the rounding. We can still measure how much noise it adds. Rounding to two decimals moves each value by a random amount between −0.005 and +0.005, so simulate that error with e = np.random.default_rng(0).uniform(-0.005, 0.005, len(df)) and compute the variance of its first difference, np.diff(e).var().
